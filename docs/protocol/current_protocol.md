# Current experimental protocol

## Status and precedence

The proposed scientific protocol is the final pre-experiment manuscript in `paper/`, dated 7 October 2026. It contains no formal model results. Historical blueprint and diagram documents preserve research context, but the manuscript's **same-text C versus matched-neutral P** comparison is authoritative. The subsequent offline lifetime overlay implements bounded scripted P/R/C state and rendering checks; it does not update the manuscript into an empirical-results paper.

## Question and population

After a controller executes a reviewer-directed action in an unfinished workflow, does the continuing applicability of the review packet affect later preservation of previously achieved, still-required goals?

Freeze a reference actor and an outcome-blind public checkpoint trigger. At each selected natural root, record the pending original action a0 and exactly one reviewer draw q, including selected action a1, packet m, and its public scope declaration. Keep malformed, out-of-scope, unchanged and failed draws in the accounting. Public format failures follow a predefined original-action/no-packet fallback; a valid-format tool failure remains a tool outcome. Do not resample based on results.

The protected set contains goals observed false earlier in the episode, true at the root, and still required at termination. Initially true properties form a separate maintained-state stratum. Empty protected sets are retained as structural-zero roots and reported separately. Hidden predicates may label evaluation strata but may never determine deployment eligibility, scope closure, prompts or fallback.

## Arms and representation

- **B_native:** execute a0 with the native message representation. This checks instrumentation effects against B.
- **B:** execute a0 with the factual controller-receipt representation.
- **S:** fixed-budget self-reconsideration; keep its distinct definition and account for all preparation/generation work.
- **A:** execute the same a1 used in the reviewer-packet arms and retain the factual receipt without packet m.
- **P0:** historical raw persistent-packet treatment from the frozen receipt adapter.
- **P:** retain exact m with a fixed neutral status header at each subsequent actor request.
- **R:** use identical first exposure, then stop reattaching the entire packet and its header after one valid actor response. Preserve the separate receipt and native history.
- **C:** use identical first exposure, then retain exact m and change only the fixed status sentence when its predeclared public action-local completion condition is satisfied.

P/R/C share the same first exposed actor request, one valid actor response, and intervening native events up to the next actor boundary. Restore fresh branches there. Rendering attempts and failed generations do not consume the one-response exposure. Terminal shared prefixes stay in the ledger with no fork. After forking, generate fresh actor/user continuations per branch; never recycle one policy's future user events into another.

The implemented narrow scope rule accepts `action_local`, `execute_target_call`, and `normal_tool_return`, tied to the deterministic ID of the actual selected call. Closure requires its actual public successful tool return and one valid actor response. Mixed, ongoing, unresolved or failed requirements do not close. A dishonest scope declaration may still close under this syntactic rule; outcome-blind semantic violations must be reported. Successful return means the call requirement was fulfilled, not that the advice was correct, a goal was repaired or the task finished.

Original user constraints never expire. The controller-selected execution is not relabeled as an observed actor generation, and an overridden original call never receives another call's result under its ID.

## Outcomes and analysis

Primary endpoint: terminal unresolved loss of at least one protected, still-required goal. Separately report immediate loss, delayed loss, transient loss with recovery, per-goal loss, official task completion, termination cause, cost and latency. Nested predicates are not independent task observations.

Primary estimand: task-macro-average reduction in loss under C versus P on the fixed reference-root distribution, accompanied by the task-completion difference. This is distinct from episode-start deployment utility. Oracle-conditioned locally preserving/changed-action strata are diagnostics, not the primary population or runtime gate.

Use nested replication of common first-exposure segments and independent suffixes. Aggregate within checkpoint, then within task, then equally across tasks. Resample tasks while preserving complete blocks and their shared-prefix dependence; examine task-family sensitivity. A common API seed is not proof of deterministic counterfactual coupling. Incomplete infrastructure blocks need separate codes and sensitivity bounds. Native max-step/error terminations remain observed task endpoints.

## Controls and acceptance criteria

Prespecify model/provider versions, prompts, task splits, public triggers, scope rule, budgets, sample design, primary endpoint and stopping conditions before confirmatory data. Calibrate P0/P wrappers, A/R removal, B_native/B instrumentation, neutral rewording, token-matched general deletion and fixed TTL alternatives. Same-character/byte-width headers do not establish provider-token equality.

Choose the minimum preservation improvement delta and tolerated task-completion loss epsilon before confirmation. A stronger improvement claim requires the primary risk-difference interval to exceed delta and completion to remain within epsilon. Broad intervals are inconclusive, not equivalence. Do not stop early because a result looks favorable or change endpoints to rescue a claim.

## Remaining preconditions

1. Freeze and verify the exact provider request mapping, role/order preservation, tool pairing, retry handling and raw usage capture.
2. Establish natural-root coverage and genuine proposal/goal structure on development tasks. Seven scripted Telecom witnesses do not estimate natural frequency.
3. Freeze confirmatory model/task/budget/sample choices and run them locally only when the operator chooses to do so.
4. Validate any expansion beyond checkpoint 0, text-only interventions and the declared assistant READ scope. Existing source does not establish arbitrary write-tool, domain, timeout or streaming support.

The archive runs no paid or formal experiment. Existing live entrypoints fail closed; a complete local experiment runner and its provider mapping require integration and independent validation.
