# Local root-runner protocol v2

This operational addendum implements a bounded portion of the final manuscript;
it does not replace its scientific claims or change its preserved DOCX/figure.
No live experiment was conducted to prepare this release.

The trigger is a pending single supported assistant call after two completed
assistant tool returns and at least one user text event. The reference trajectory
uses original actor actions and is collected before treatment branching. All
reached roots up to a predeclared cap are retained, without hidden goal gates.
Each root receives exactly one reviewer draw shared by A/P0/P/R/C. S separately
uses one actor-model reconsideration under the same response-token cap. It is
not a realized-token or currency match. No valid proposal is resampled.

Supported assistant actions are official READ tools and enable/disable roaming.
A WRITE may change real carrier state. A normal return alone does not establish
repair. Only an action-local declaration matching the derived call ID, actual
normal return and one valid actor response can change C's status. P/R/C share
all first-exposure content and intervening public events before independent
suffixes. C/P later differ only in the fixed-width status sentence; this is not
a provider-token equality guarantee. R removes packet/header, retaining receipt
and history. P0 byte parity with another historical renderer is not assumed.

Protected goals were initially false, true at the reference root and remain
required under the fixed task. Initially true properties are recorded separately.
There is no dynamic still-required mask for revoked or changed user requests.
Zero protected-goal roots remain structural zeros. Shadow assertions and official
evaluation cannot influence trigger, draw, action selection or closure.

Received reviewer truncation/refusal/malformed output consumes the draw and
falls back to original action with no packet. Actor/user received-invalid outputs
(empty/refusal/truncation/bad tool JSON, multiple calls or hallucinated tool) map
to native AGENT_ERROR/USER_ERROR completion-zero endpoints. Mixed text/tool uses
the upstream communication-error endpoint. An adapter handles upstream's earlier
empty-message validation without inventing successful content. Original received
responses remain in private evidence. Unsupported known WRITEs, bad transport
envelopes, restoration failure and unavailable/unknown provider results are
explicit missingness. Native max-step/error failures remain observed outcomes.

The assigned root/arm/repetition ledger precedes proposal requests. A terminal
common segment contributes one endpoint per arm, not cloned future repeats.
Inference averages within segment, root and task, then resamples paired task
contrasts. Missing bounds use the assigned endpoint population; they do not
pretend to bound unobserved roots after a failed reference trajectory. Reference
failures therefore prevent the confirmation verdict. Equal-family sensitivity
is a point estimate only.

Confirmation binds source, task hashes, model versions, margins, sample,
repetitions, limits and exclusions before data collection. Built-in and declared
prior-run exposures exclude matching and near-family tasks. Confirmation units
share no normalized fault component. This is a conservative lexical restriction,
not a causal or statistical proof of independence. The operator must justify the
independent units and unseen attestation. A local freeze is not preregistration.
Mock runs can exercise machinery but never produce model effect estimates.

Costs retain all physical attempts and unknown usage/prices. Logical path totals
include shared reference/draw/common requests plus own suffixes; physical totals
deduplicate that sharing. B/B_bare exclude reviewer cost; S includes only its
self-review. Raw responses, cost details and checkpoints stay private.

Recovery replays saved model responses and reconstructs local environment state,
never regenerating a saved proposal. Initialization and mutating history execute
once in fresh objects. Unknown dispatched calls require explicit abandon/retry
choices; retries acknowledge possible duplicate billing and consume remaining
original per-request and physical quotas. The original wall budget includes the
pause. Any divergent payload, changed source/config, wrong reported model,
redacted replay payload or damaged journal fails closed. No remote cancellation
or exactly-once provider guarantee is offered.

## Telecom instance-default isolation

The pinned upstream user toolkit has a class-level mutable VPN default. The local
factory assigns each environment its own pristine VpnDetails before initialization,
using values from the pinned source rather than copying a possibly polluted class
attribute. Within-instance VPN aliasing remains upstream behavior; no state is
shared between independent environments. make/restore use this factory, and a
dedicated registry domain routes the official evaluator's schema, predicted and
gold constructors through it. The evaluation algorithm and original telecom
registry entry remain unchanged. Vendored upstream bytes are not patched.

The bad_vpn regression task is now development-exposed and excluded from future
confirmation along with its near families. Metadata-only freeze tests use a
different unexecuted task. The isolation adapter is included in source bindings.
