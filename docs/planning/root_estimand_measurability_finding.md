## 1 主终点与可测前提

根实验主终点 **L = 终止时「受保护目标」的丢失**，受保护目标定义为「初始为假、root 时为真、终止时仍需要」
（文档 §7.2）。要使 L 非退化（可 0 可 1，而非定义产生的结构零），须同时满足四个条件：

1. 某目标在轨迹**中途**变真（可保护）且终止时仍需要；
2. 该目标**可被后续动作回退**（否则恒为 L=0）；
3. 在「目标已真 + 仍有未完成工作」的窗口内存在一个**受支持的待执行 Assistant 调用**
   （否则公开触发器无法在保护窗口内触发）；
4. C 组「公开完成条件关闭」相对 P 组「持续中性头」能改变该目标的终止命运。

  无法捕获；9 轨迹 55 候选 0 protected-and-unmet。
- **可分离 roaming 稀有且不可复现**：唯一命中是 round-1 t6-s0（idx70，3 故障，向量 `[True,False]`，
  5 个保护且未满足候选）。但 §8.4 定向扩展——6 个「≥2 仅降速故障」多故障家族
  （idx70/71/73/146/152/187）×4 start=24 轨迹——**复现 0 次分离**，且 **idx70 本身 4 个 start 全 0**。
  这证明 round-1 的单次命中是**稀有随机排序**（用户恰在 Actor 早期 READ 前修好漫游），非可复现结构性质。

## 4 §13 有边界负结果（正式声明）

在**冻结的 Telecom 任务池**（commit 4ce7c03，2285 个 telecom 任务）中，按文档 §13 的要求——
修正触发语义（READ∪允许 WRITE 并集，已被 t6-s0 的 5 个 READ 候选直接验证）、完成 reference 覆盖、
做了合理的 §8.4 任务扩展之后——自然形成的「受保护且未满足」窗口**几乎从不与可捕获的触发边界重合**。
据此：

- **根实验八臂主终点 L(P)−L(C) 在本池中不可测**：非空保护 root 仅 1 个、仅 1 个任务，远低于任何
  有意义的统计或工程覆盖门槛。八臂根实验**无法产出对 L 的有效因果对比**，故**不执行**该主终点批次。
- 这**不是**「效应为零」的断言，也**不是**旧 G3/G4「触发器只能在 WRITE 前触发、故 L 必然不可测」的
  错误判断（该旧判断含事实错误，已被 `reports/audit_corrections.md` 与本文件的真实轨迹证据修订）。
  准确表述是：**该任务池无法测量该估计量**。
- **禁止**用人工续写、诱导 Reviewer 选错、隐藏状态实时挑 root 来凑覆盖（文档 §7.3 line240）。
  本负结果基于实际尝试与正确触发语义，未伪造覆盖、未提前断言不可能。
